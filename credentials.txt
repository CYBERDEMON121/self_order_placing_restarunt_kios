MILA'S RESTAURANT CREDENTIAL CONFIGURATION
==========================================

No real passwords or secrets are stored in this repository or in this file.

ADMIN LOGIN
-----------
Username:
    Read from ADMIN_USERNAME.
    Default when ADMIN_USERNAME is not set: admin

Password:
    Read from ADMIN_PASSWORD.
    There is intentionally no default password.
    Set it locally before starting the application.

Example for PowerShell:
    $env:ADMIN_USERNAME = "admin"
    $env:ADMIN_PASSWORD = "<choose-a-password>"
    ruby app.rb

Example for bash:
    export ADMIN_USERNAME=admin
    export ADMIN_PASSWORD='<choose-a-password>'
    ruby app.rb

SESSION SECRET
--------------
Read from SESSION_SECRET.
If it is not set, the application generates a temporary random value when the
process starts. Set a long random value in production to keep sessions valid
across restarts.

Example:
    export SESSION_SECRET='<long-random-secret>'

SQLITE DATABASE
---------------
DATABASE_FILE:
    Optional path to the SQLite database file.
    Default: restaurant.sqlite3
    The application creates the database and tables automatically.

Legacy import files:
    PRODUCTS_FILE and ORDERS_FILE are read once when a new database is created.
    They are not used for normal runtime reads or writes after migration.
    Default products file: products.json
    Default orders file: order_placed.json
    Additional legacy orders file: order_placed

ORDER RECORDS AND QR TRACKING
-----------------------------
ORDER_RECORDS_FILE:
    Optional path to the JSON order ledger synchronized from SQLite.
    Default: order_records.json
    Each record includes the order code, placement date, time, timestamp, items,
    total, payment state, status, public token, and ready time.

PUBLIC_BASE_URL:
    Optional externally reachable base URL used inside QR codes.
    Set this when the kiosk is running on localhost and a phone must scan
    the QR code, for example: http://192.168.1.20:4567
    Without it, the current request base URL is used.

Runtime SQLite tables:
    products
    orders
    order_items
    app_meta

DEPENDENCY
----------
Install the SQLite and QR drivers if they are not already available:
    gem install sqlite3 --no-document
    gem install rqrcode --no-document

PAYMENT SIMULATOR
-----------------
The checkout uses only approved or declined simulation outcomes.
No card number, card password, CVV, bank username, bank password, or payment
API secret is collected or required.
